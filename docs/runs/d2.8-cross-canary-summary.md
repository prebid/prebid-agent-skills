## 4. F2 priority recommendation

The F3 spike data argues for the following F2 sprint sequence. Each tier groups fixes by leverage; lower-cost-higher-leverage first.

### Tier 0 — universal checkstyle clearance (clears Gate 4 across corpus; ~2 hours engineering)

These 4 fixes touch ≤ 1 template per fix and affect ≥ 5/6 canaries. Pure template edits, no schema changes, no ctx wiring.

1. **F-new-58**: reorder `BidderDeps` import in `configuration.java.j2`
2. **F-new-60**: fix scenario-method-name generation (camelCase) in `bidder-test.java.j2` + `it-test.java.j2`
3. **F-new-96**: conditional import of `JsonNode` in `bidder.java.j2`
4. **F-new-61**: wrap long string literals in `it-test.java.j2`

Expected outcome: Gate 4 clears for all 6 canaries. Gate 1 still fails on F-new-56 + F-new-57.

### Tier 1 — universal javac clearance (clears Gate 1 + 2 + 3 for canaries 1+4+6+2+3; ~4 hours engineering)

1. **F-new-56**: drop `JsonProcessingException` from multi-catch in `bidder.java.j2`
2. **F-new-57**: Spring DI factory ctx-aware (use `<bidder>ConfigurationProperties` when Rule 35 fires, else `mapper`)
3. **F-new-59**: reorder `lombok.Data` import in `configuration-properties.java.j2`
4. **F-new-79**: align AdverxoBidderConfiguration internal class name with file name

Expected outcome: Gate 1 + 2 + 3 reachable for kobler, aax, adkernelAdn, adverxo, thetradedesk. Vungle still has F-new-90 javac issues.

### Tier 2 — vungle-specific javac (clears Gate 1 for vungle; ~2 hours)

1. **F-new-90**: replace `BidderUtil.isResponseStatusCodeNoContent` with the actual upstream-Java helper name (likely `HttpUtil` family); same for `checkResponseStatusCode`

After Tier 0-2: All 6 canaries reach Gate 1 PASS. Gates 2-3 measurable for first time.

### Tier 3 — behavioral fidelity (the big rocks; corpus-wide leverage; ~8-15 hours)

These are larger surface changes but the highest-leverage SKILL improvements. Order by leverage:

1. **F-new-78** (entity-mutation chains): every bidder with `mutates_request:true` (~5/6 canaries) — Imp/Site/App/Banner/Video toBuilder rebuild emission
2. **F-new-50 family** (endpoint resolution): 4 new template branches (`dev-prod-toggle`, `template-macro`, `multi-token-substitution`, `query-parameter-augmentation`) + ctx schema additions
3. **F-new-86** (F3 Site→App synthesis): vungle-specific but ADR-007 master sample
4. **F-new-100** (F4 bid-post-processing macros): thetradedesk-specific but ADR-007 master sample
5. **F-new-91 + F-new-92** (vungle imp.ext repack + buyer-UID): coupled pair

### Tier 4 — quality/cosmetic (anytime; ~2 hours)

- F-new-66 (usersync YAML block-style)
- F-new-67/69/72 (empty geoscope guard)
- F-new-69-canary-4 (family-shape classifier `meta.empire_*` consultation)
- F-new-93 (custom HTTP header emission)
- F-new-62 (execution-plan §183 docs fix)
